> Halo saya baru belajar number system menggunakan ```bin.num oct.num hex.num int.ns``` untuk mengubah nomor menjadi nomor system seperti Binary, Octal, Hexadecimal

### Structur
```python
#source_file -> -system.number.py

# Menu
	Menu

# Fungsi if
	1-6

2. Number to Octal :oct.
3. Number to Hexadecimal :hex.

4. Binary to Number	:int.binary, 2
5. Octal to Number	:int.octal, 8
6. Hexadecimal to Number	:int.hexadecimal, 16
```
